# Lumina — AI Image Creator

Темна адаптивна домашня сторінка сервісу для створення AI-зображень, стилістично натхненна Leonardo AI. Основний акцент зроблено на точному відтворенні структури та візуальної атмосфери: бічна навігація, кінематографічний hero-блок, поле промпту, режими створення, добірка blueprint-шаблонів і галерея робіт спільноти.

Застосунок містить робочу студію генерації через Gemini API. Із головної сторінки вона відкривається кнопкою **Generate** або пунктом **Image** у бічній навігації.

## Можливості

- адаптивна бічна панель навігації;
- мобільне меню;
- hero-блок із полем для промпту;
- режими Image, Video, 3D, Audio, Blueprints та Upscaler;
- горизонтальна галерея Featured Blueprints;
- секція Community Creations;
- hover-ефекти й базові інтерактивні стани;
- локальні графічні ресурси без залежності від зовнішніх URL.
- генерація через актуальні моделі Nano Banana;
- імпорт промптів із `.txt` та `.docx`;
- пакетна генерація кількох промптів і варіантів;
- завантаження результатів та базовий Canvas-редактор.

## Технології

- React;
- Vite;
- Lucide React;
- звичайний CSS, вбудований у React-компонент.

## Вимоги

Перед запуском встановіть:

- [Node.js](https://nodejs.org/) версії 18 або новішої;
- npm, який постачається разом із Node.js.

Перевірити встановлені версії можна командами:

```bash
node --version
npm --version
```

## Як запустити застосунок

### 1. Відкрийте папку проєкту

У PowerShell:

```powershell
cd "D:\programs\AI Image Creator"
```

В іншій операційній системі перейдіть до фактичної папки, у якій розташований проєкт.

### 2. Встановіть залежності

```bash
npm install
```

Команда встановить React, Vite та бібліотеку іконок Lucide React.

### 3. Запустіть режим розробки

```bash
npm run dev
```

Vite виведе локальну адресу в терміналі. Зазвичай це:

```text
http://localhost:5173
```

Відкрийте цю адресу у браузері. Для зупинки сервера натисніть `Ctrl + C` у терміналі.

## Налаштування Gemini API key

Отримайте ключ у [Google AI Studio](https://aistudio.google.com/app/apikey). Ключ не вводиться в інтерфейсі застосунку та зберігається лише в локальному файлі `.env.local` у корені проєкту.

Створіть у корені проєкту файл `.env.local`:

```env
GEMINI_API_KEY=ваш_ключ
```

Після зміни файлу перезапустіть `npm run dev`.

Ключ читається локальним Vite-сервером і не додається до браузерного JavaScript. Запити зі сторінки проходять через локальний маршрут `/api/gemini/generate`.

### Якщо PowerShell блокує команду `npm`

Якщо з'являється помилка про заборону виконання `npm.ps1`, використовуйте Windows-команду `npm.cmd`:

```powershell
npm.cmd install
npm.cmd run dev
```

Змінювати системну Execution Policy для запуску цього проєкту не обов'язково.

## Інші команди

Створити production-збірку:

```bash
npm run build
```

Готові файли з'являться в папці `dist`.

Переглянути production-збірку локально:

```bash
npm run preview
```

Якщо ви використовуєте `npm.cmd`, відповідні команди мають вигляд `npm.cmd run build` і `npm.cmd run preview`.
